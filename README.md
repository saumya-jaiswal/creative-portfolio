# Saumya Jaiswal - Portfolio

Personal portfolio site covering video content, graphic design, and creative writing work.

Live at [saumyajaiswal.netlify.app](https://saumyajaiswal.netlify.app)

## Built with

Plain HTML, CSS, and JavaScript. No build step or framework, styled with CSS custom
properties and Google Fonts (Playfair Display, DM Sans, DM Mono).

## Structure

Single page site (`index.html`) with a fixed nav, smooth scroll, and sections for
video work, graphic design, writing, and contact.

## Deployment

Hosted on Netlify.
